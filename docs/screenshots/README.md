# スクリーンショット置き場

ここに実機のスクリーンショットを配置すると、リポジトリ直下の `README.md` に自動的に表示される。

以下のファイル名で置くと、README 側の変更なしにそのまま反映される。

| ファイル名 | 内容 |
|---|---|
| `home.png` | ホーム画面（トレーニング履歴の一覧） |
| `input.png` | 記録の入力画面（種目・セットの入力） |
| `detail.png` | トレーニング詳細画面 |
| `copy.png` | 「前回コピー」で複製した直後の画面（前回の内容が引き継がれている状態） |

画像は `.png` か `.jpg` を想定（拡張子を変える場合は `README.md` 側のパスも合わせて変更する）。
実機や Android Studio のエミュレータでスクリーンショットを撮り、このフォルダに置くだけでよい。
